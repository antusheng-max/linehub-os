# 安全模型

## 信任边界

- 浏览器仅通过 LuCI/rpcd 的认证授权访问管理接口。
- LuCI 不能直接执行 shell 网络命令；它提交受校验的 UCI 变更，并通过 ubus 请求受限操作。
- `linehubd` 是配置协调边界，负责 schema 校验、敏感字段脱敏、审计事件和失败处理。
- OpenWrt 继续作为网络服务、进程权限和 nftables 执行边界的权威来源。

## 凭据和日志

PPPoE 用户名与密码只存放于设备受保护的运行配置中。版本库、示例、fixture、日志、诊断输出和 API 响应不得含真实凭据、密钥、令牌、证书或设备 MAC。示例 `example-not-a-secret` 不可用于任何真实网络。

## 默认防护

- 最小化 rpcd ACL：读状态与写配置分开授权。
- 配置提交前校验 VLAN ID、MAC 格式、地址族开关、权重边界、池成员和策略引用。
- 规则生成必须使用专用 table/chain/mark 范围，避免覆盖用户或 OpenWrt 管理的规则。
- 恢复/回滚操作必须幂等，并保留不会把 LAN 管理面锁死的安全路径。
- 诊断默认只读、脱敏、限权，且不发送凭据到外部探测目标。

## 威胁与缓解

错误策略可能造成流量泄漏或非对称路由；连接标记恢复、按地址族表路由和前缀来源校验降低该风险。健康检查被错误目标误导可能触发抖动；阈值、恢复计数和多状态展示可降低频繁切换。Web 输入导致配置注入的风险由 UCI schema 校验和不拼接 shell 命令处理。
